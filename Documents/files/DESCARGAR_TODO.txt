🚀 INSTALACIÓN (3 pasos)
═══════════════════════════════════════════════════════════════

PASO 1: Descargar todos los archivos
   └─ Descargar los 6 archivos principales (arriba)
   └─ Guardar en una carpeta: ~/bots_intranet/

PASO 2: Instalar Mullvad (en Kali)
   bash install_search.sh
   
   O manualmente:
   sudo curl -fsSLo /usr/share/keyrings/mullvad-keyring.asc \
     https://repository.mullvad.net/deb/mullvad-keyring.asc
   
   echo "deb [signed-by=/usr/share/keyrings/mullvad-keyring.asc \
     arch=$(dpkg --print-architecture)] \
     https://repository.mullvad.net/deb/stable stable main" | \
     sudo tee /etc/apt/sources.list.d/mullvad.list
   
   sudo apt update
   sudo apt install mullvad-vpn

PASO 3: Ejecutar
   cd ~/bots_intranet/
   
   source search_env/bin/activate
   python3 orchestrator_links.py --schedule
